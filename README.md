# Number Guessing Game

## Description

This project is a simple command-line number guessing game written in Python.

The game generates a random number between 1 and 100. The player is prompted to guess the number, receiving feedback after each attempt indicating whether their guess is too low or too high. The number of attempts is tracked. If the player exceeds ten attempts without guessing correctly, the correct number is revealed and the game ends. If the player guesses correctly, they are congratulated and informed of the total number of attempts used.

This game demonstrates basic usage of random number generation, user input handling, conditional statements, and loops in Python.

## Features

- Random number generation
- User-guided guessing
- Attempt tracking (up to ten attempts)
- Feedback for each guess ("too high" or "too low")
- Game win/loss messaging

## How to Use

Simply run the Python script in your terminal and follow the on-screen prompts to play.

## Requirements

- Python 3.x
